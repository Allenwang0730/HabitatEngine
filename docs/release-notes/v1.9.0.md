## Habitat 1.9.0 — 让 AI Agent 操控安卓手机

**下载**：绝大多数手机装 `app-standard-arm64-v8a-release.apk`；不确定 CPU 架构就装 `app-standard-universal-release.apk`。Android 10+。

### 亮点
- **自主模式重构：DeepSeek 规划 + Jev 执行 + 代码控制**。先拆步骤（每步带屏幕上可验证的完成条件），能用设备工具就直接用，卡住时从当前屏幕重规划，最后按屏幕证据复核。
  真机评测（vivo / Android 16，7 类任务，两轮各 × 2 次，adb 独立验证）：有规划时 Jev、DeepSeek 每轮都是 **14/14**（合计 28/28），无规划 6–10/14。方法与原始数据见 [docs/EVAL.md](../EVAL.md)。
- **设备工具**：设置页直达、开关 WLAN/蓝牙/手电/免打扰、调亮度音量、读电量/时间/设备/网络。改设备状态的工具必须由用户目标原文点名。
- **页面状态与导航记忆**：开关开/关、滑块百分比进入候选；导航栈告诉模型"在哪一层、返回到哪、哪些入口试过"。
- **安全加固**：MCP 服务默认只监听本机、每台设备随机令牌、高危节点远程默认拒绝；Shell 变量自动转义；文件路径守卫；密钥加密存储。
- **界面重做**：新设计系统，工作流列表、编辑器、结构图、Agent 页、设置页重做。
- **引擎可通过 JitPack 引入**：`implementation("com.github.Allenwang0730:HabitatEngine:v1.9.0")`。

### 注意
- 默认 `standard` 包**不含**微信读屏服务（它冒用 Google `SelectToSpeakService` 类名，只适合自用）。需要时自行构建：`./gradlew :app:assembleWechatDebug`。
- 国内网络直连 Jev 返回 HTTP 451：手机开代理/VPN，或在 Agent 页「Jev 代理」填 `127.0.0.1:<电脑代理端口>` 并 `adb reverse tcp:<端口> tcp:<端口>`。
- 旧版默认令牌 `habitat-dev-token` 已作废；电脑侧连接需 `adb forward tcp:8931 tcp:8931` 和 Agent 页里的新令牌。

完整变更见 [CHANGELOG.md](https://github.com/Allenwang0730/HabitatEngine/blob/main/CHANGELOG.md)。
